# Verba — Голосовое распознование для разработчиков

**Verba** — это лёгкое Android-приложение для распознавания речи на устройствах без постоянного подключения к интернету.  
Использует локальную модель [Vosk](https://alphacephei.com/vosk/) для приватного и надёжного преобразования голоса в текст.

## 🔹 Основные возможности
- Работает **оффлайн** — данные не покидают устройство  
- Поддержка **русского и других языков** (в зависимости от модели)  
- Настройка:
  - Темы интерфейса (светлая / тёмная / системная)  
  - Уровень приглушения звука  
  - Имя Intent и ключ для передачи результата другим приложениям  
- Оптимизировано для **планшетов в альбомной ориентации**

## 📦 Технологии
- **Vosk Android SDK** — оффлайн-распознавание речи  
- **Material Design 2** — современный и адаптивный интерфейс  
- **Java** — полностью совместимо с Android 9+

## 🚀 Назначение
