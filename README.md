# Verba

Android-приложение для голосового ввода текста в сторонние приложения. Использует офлайн-распознавание речи на базе [Vosk](https://alphacephei.com/vosk/) и передаёт результат через broadcast-интент — без интернета, без облаков.

Разработано для интеграции с ассистентами и автоматизационными приложениями (например, "Ассистент Дуся").

***

## Как это работает

1. Пользователь нажимает на иконку **MVoice** или стороннее приложение отправляет интент `org.verba.VOICE`
2. Запускается `VoiceService` — foreground-сервис с оверлеем поверх других окон
3. Сервис слушает микрофон, распознаёт речь офлайн через Vosk
4. Результат отправляется broadcast-интентом в целевое приложение

***

## Возможности

- Офлайн-распознавание речи (Vosk)
- Запуск голосового ввода через иконку в лаунчере или внешний интент
- Передача результата через настраиваемый broadcast-интент
- Оверлей с отображением распознанного текста (опционально, управляется через debug-режим)
- Выбор аудиопотока (Sonification / Notification / Media)
- Регулировка уровня снижения громкости во время записи
- Настройка таймаутов (длинная и короткая пауза)
- Светлая / тёмная / системная тема
- Автозапуск при загрузке устройства

***

## Требования

- Android 6.0 (API 23) и выше
- Разрешения:
  - `RECORD_AUDIO` — запись микрофона
  - `SYSTEM_ALERT_WINDOW` — оверлей поверх других окон
  - `FOREGROUND_SERVICE` — фоновая служба
  - Исключение из оптимизации батареи

***

## Настройка

| Параметр | По умолчанию | Описание |
|---|---|---|
| Intent Name | `com.dusiassistant.INPUT` | Action целевого broadcast-интента |
| Text Key | `text` | Ключ extra с распознанным текстом |
| Timeout Long | `3200 мс` | Пауза для завершения фразы |
| Timeout Short | `400 мс` | Пауза между словами |
| Volume Level | `60` | Уровень снижения громкости при записи |
| Audio Stream | `Sonification` | Аудиопоток для управления громкостью |
| Debug Voice Input | `выкл` | Показывать оверлей с результатом |

***

## Интеграция

Запуск голосового ввода из стороннего приложения:

```java
Intent intent = new Intent("org.verba.VOICE");
intent.setPackage("org.verba");
startActivity(intent);
```
